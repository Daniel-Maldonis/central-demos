## 🚀 Como funciona o repositório

1. **Pastas Enumeradas por Ranking (`/ranking/[XX-nome-do-cliente]/`)**:
   - Cada pasta contém o site novo (`index.html`), o comparativo de vendas (`proposta.html`) e o editor visual (`[slug]-editor.html`).
   - A numeração direta reflete a probabilidade de fechamento baseada em autoridade Google, ticket médio e gravidade do problema no site atual.

2. **Pastas de Clientes por Slug (`/clientes/[nome-do-cliente]/`)**:
   - Mantidas para compatibilidade direta de links com Vercel e HostGator.
   - Rotas limpas e links individuais para cada cliente.

3. **Página Principal (`/index.html`)**:
   - Catálogo interativo com visualizador responsivo, filtros e botões de cópia direta de links.
